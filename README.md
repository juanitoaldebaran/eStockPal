## Overview

**eStockPal** is an AI-driven stock analysis and prediction platform built using **Flask (Python)** for the backend and **React.js (Next.js)** for the frontend.


## Features

### Market Data & Analysis
- Fetches **real-time** and **historical** stock data from [Finnhub.io](https://finnhub.io/)
- Displays market stats such as:
  - Current price
  - Open, High, Low, Close
  - Volume and percentage change

### Machine Learning Predictions
- Uses **LSTM neural networks** (Long Short-Term Memory) to predict stock trends
- Generates short-term **price forecasts**
- Provides visual trend insights: Bullish / Bearish / Neutral

### Interactive Dashboard
- User inputs stock ticker (e.g., `AAPL`, `MSFT`, `TSLA`)
- Visualizes:
  - Historical data chart  
  - Predicted price chart  
  - Market sentiment trend
